Quiz Interactive multiple choice quiz about the subject you are developing on your Web site. Once the quiz has been completed, it gives the user a mark on how he/she performed. This should be time limited. When the quiz is finished should also display the summary of the user performance (which answers were correct or incorrect, and how long it took to complete the quiz). The user will get 2 marks for each correct answer, and -1 for each wrong answer. The quiz should consist of 10 questions. The background colour of the page should change according to the awarded mark.
